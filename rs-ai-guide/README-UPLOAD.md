# rs-ai-guide

将本目录中的文件直接上传到 `YanghuiSong/YanghuiSong.github.io` 仓库的 `rs-ai-guide/` 目录。

最终结构：

```text
rs-ai-guide/
├── index.html
├── guide.md
└── assets/
    ├── guide.css
    └── guide.js
```

部署后访问：

`https://yanghuisong.github.io/rs-ai-guide/`

说明：
- 不需要修改根目录 `index.html`
- 不需要修改 `assets/site-data.js`
- 不要把本页面加入根目录 `sitemap.xml`
- `index.html` 已加入 `noindex, nofollow, noarchive`
