遥感图像解译 × 人工智能科研学习导航

面向刚进入实验室的新生。
这不是打卡式学习计划，也不是“所有模型都必须会”的清单，而是一份知道该读什么、为什么读、读到什么程度的科研导航。

2. 通用计算机视觉：只抓住这 5 篇主线论文

新生不需要先把几十年 CV 历史全部补完。ResNet、U-Net、FPN、YOLO 等应当知道基本概念，但如果准备进入当前遥感 AI 科研，更建议先把下面五篇真正读明白。

2.1 ViT — 从 CNN 进入视觉 Transformer

An Image is Worth 16×16 Words: Transformers for Image Recognition at Scale

  • Paper: https://arxiv.org/abs/2010.11929
  • Code: https://github.com/google-research/vision_transformer
  • Bilibili: https://www.bilibili.com/video/BV1htjzzsEYe/

读什么： patch embedding、token、self-attention、position embedding，以及“图像如何变成序列”。

2.2 Swin Transformer — 为什么视觉需要层次化特征

Swin Transformer: Hierarchical Vision Transformer using Shifted Windows

  • Paper: https://arxiv.org/abs/2103.14030
  • Code: https://github.com/microsoft/Swin-Transformer
  • Bilibili: https://www.bilibili.com/video/BV13L4y1475U/

读什么： window attention、shifted window、multi-scale feature。它能帮助理解为什么检测和分割不能只依赖单尺度 token。

2.3 DETR — 现代 query-based detection 的起点

End-to-End Object Detection with Transformers

  • Paper: https://arxiv.org/abs/2005.12872
  • Code: https://github.com/facebookresearch/detr
  • Bilibili: https://www.bilibili.com/video/BV1T6421F7tR/

读什么： object query、Hungarian matching、set prediction。后续大量检测、分割和 SAM3 中的 detector 都能看到 DETR 的影子。

2.4 Mask2Former — 统一理解现代分割

Masked-attention Mask Transformer for Universal Image Segmentation

  • Paper: https://arxiv.org/abs/2112.01527
  • Code: https://github.com/facebookresearch/Mask2Former
  • Bilibili: https://www.bilibili.com/video/BV1EA22YnEY1/

读什么： mask classification、query、masked attention，以及 semantic / instance / panoptic segmentation 如何被统一到一个框架中。

2.5 CLIP — 进入开放词汇与视觉语言模型

Learning Transferable Visual Models From Natural Language Supervision

  • Paper: https://arxiv.org/abs/2103.00020
  • Code: https://github.com/openai/CLIP
  • Bilibili: https://www.bilibili.com/video/BV1NM411a7CP/

读什么： image encoder、text encoder、contrastive learning、zero-shot classifier、prompt template、cosine similarity。

对遥感开放词汇分类、检测和分割而言，CLIP 是必须真正理解的基础。不要只会调用 encode_image() 和 encode_text()。

3. 接下来必须知道的视觉基础模型

这一部分不要求按年份“全读”，重点是理解现代视觉系统正在从单任务网络转向可提示、开放词汇、可迁移的基础模型。

3.1 DINOv3 — 强视觉表征

  • Paper: https://arxiv.org/abs/2508.10104
  • Code: https://github.com/facebookresearch/dinov3
  • Bilibili: https://www.bilibili.com/video/BV1s7JCzbETY/

重点关注：

  • self-supervised representation；
  • frozen visual features；
  • dense feature；
  • linear probing；
  • satellite-pretrained DINOv3 权重。

DINO 系列更像是在学习一个很强的“视觉表示空间”；CLIP 则把视觉表示进一步对齐到语言空间。理解两者差异非常重要。

4. SAM 系列：从“提示分割”到“文本概念分割”

SAM 1

Segment Anything

  • Paper: https://arxiv.org/abs/2304.02643
  • Code: https://github.com/facebookresearch/segment-anything

理解：

Image Encoder
+ Prompt Encoder
+ Mask Decoder

SAM1 的核心不是“分割精度天下第一”，而是把 segmentation 变成了 promptable task。

SAM 2

Segment Anything in Images and Videos

  • Code: https://github.com/facebookresearch/sam2

理解：

  • image + video unified segmentation；
  • memory mechanism；
  • object tracking；
  • prompt propagation。

SAM 3 / SAM 3.1

SAM 3: Segment Anything with Concepts

  • Paper: https://arxiv.org/abs/2511.16719
  • Code: https://github.com/facebookresearch/sam3
  • Bilibili（SAM1→SAM3）：https://www.bilibili.com/video/BV1Px9aBPEft/

SAM3 是值得特别关注的一代：除了点、框、mask 等视觉提示，还把短文本概念直接引入检测、分割和跟踪；官方在 2026 年进一步发布了 SAM 3.1。

阅读时重点看：

  • text-conditioned detection；
  • presence token；
  • detector + tracker；
  • open-vocabulary concept segmentation；
  • “concept”与传统固定类别 segmentation 的区别。

5. Grounding 系列：让语言真正落到空间位置

Grounding DINO

  • Paper: https://arxiv.org/abs/2303.05499
  • Code: https://github.com/IDEA-Research/GroundingDINO
  • Bilibili: https://www.bilibili.com/video/BV1rjgBzHEBW/

它解决的是：

文本描述
   ↓
图像中对应目标
   ↓
Bounding Box

重点理解：

  • open-set / open-vocabulary detection；
  • text-conditioned object query；
  • phrase grounding；
  • language 与 detection feature 如何交互。

Grounding DINO + SAM

这是非常重要的组合范式：

Text
 ↓
Grounding DINO
 ↓
Box
 ↓
SAM
 ↓
Mask

它代表了一个很有价值的研究思想：

语言模型/grounding 模型负责“找什么”，专业分割模型负责“切多准”。

后面的遥感 MLLM 与 Agent 也经常沿用类似的职责分工。

6. 从 VLM 到 MLLM：理解三代模型即可

BLIP-2

  • Paper: https://arxiv.org/abs/2301.12597
  • Code: https://github.com/salesforce/LAVIS
  • Bilibili: https://www.bilibili.com/video/BV18u4y137ZV/

看懂 Q-Former 如何连接 frozen vision encoder 与 frozen LLM。

LLaVA

  • Paper: https://arxiv.org/abs/2304.08485
  • Code: https://github.com/haotian-liu/LLaVA
  • Bilibili: https://www.bilibili.com/video/BV1nw4m1S7nZ/

看懂：

Vision Encoder
  ↓
Projector
  ↓
LLM
  ↓
Language Response

以及 visual instruction tuning 为什么能让 LLM“看图聊天”。

Qwen2.5-VL / Qwen3-VL

  • Qwen2.5-VL: https://github.com/QwenLM/Qwen2.5-VL
  • Qwen3-VL: https://github.com/QwenLM/Qwen3-VL
  • Bilibili（Qwen2.5-VL）: https://www.bilibili.com/video/BV1wnbGzbEdy/
  • Bilibili（Qwen3-VL）: https://www.bilibili.com/video/BV1Vx421m7r7?p=3

建议重点观察现代通用 MLLM 已经从：

Image → Caption / VQA

逐渐走向：

Image / Video
→ Spatial Reasoning
→ Grounding
→ Tool Use
→ Agent

因此，做遥感 MLLM 时不能默认“遥感专用模型一定优于通用 MLLM”。2026 年的系统评测已经表明，强通用 MLLM 在部分遥感理解任务上可以匹配甚至超过专用 RS-MLLM。

7. 遥感 AI：先知道三篇承上启下的工作

下面三篇并非 2026 最新，但它们非常适合理解“通用视觉模型如何进入遥感”。

RemoteCLIP — 遥感视觉语言预训练

  • Paper: https://arxiv.org/abs/2306.11029
  • Code: https://github.com/ChenDelong1999/RemoteCLIP

值得读的原因：理解为什么自然图像 CLIP 直接迁移到遥感会产生 domain gap，以及遥感 image-text alignment 如何构建。

SegEarth-OV — Training-Free Open-Vocabulary Remote Sensing Segmentation

  • Paper: https://arxiv.org/abs/2410.01768
  • Code: https://github.com/likyoo/SegEarth-OV
  • Venue: CVPR 2025 Oral

值得读的原因：它把 CLIP/VLM 的开放词汇能力直接用于遥感密集预测，而且强调 training-free inference，是理解 2026 年 OVRSS 工作的重要前置论文。

GeoChat — 遥感 MLLM

  • Paper: https://arxiv.org/abs/2311.15826
  • Code: https://github.com/mbzuai-oryx/GeoChat
  • Venue: CVPR 2024

值得读的原因：从传统 image-text retrieval / captioning 进入真正的遥感多模态对话、grounding 与高分辨率理解。

8. 2026 遥感前沿：基础模型

8.1 TESSERA — 时间序列 Earth Foundation Model

  • Venue: CVPR 2026
  • Code: https://github.com/ucam-eo/tessera
  • Paper / project information: repository 中提供

TESSERA 面向 satellite time-series，强调像素级时序地球表征。

建议关注的问题：

  • 为什么 EO foundation model 不应该只处理单张 RGB？
  • seasonal / temporal pattern 如何进入 representation？
  • 10 m resolution、年度 embedding 的能力边界在哪里？

这是理解“Earth Foundation Model ≠ ImageNet 大模型”的好例子。

8.2 GeoSANE — Learning Geospatial Representations from Models, not Data

  • Venue: CVPR 2026
  • Code: https://github.com/HSG-AIML/GeoSANE

这篇工作的切入点很特别：研究从已有模型本身而不是重新收集海量数据来学习地理空间表示。

建议把它作为“foundation model 下一步还能怎么做”的思想性论文，而不是只盯着更大的数据和参数量。

9. 2026 遥感前沿：Open-Vocabulary Segmentation

这是目前遥感视觉里非常活跃的一条线。

9.1 RSKT-Seg

Exploring Efficient Open-Vocabulary Segmentation in the Remote Sensing

  • Venue: AAAI 2026 Oral
  • Paper: https://arxiv.org/abs/2509.12040
  • Code: https://github.com/LiBingyu01/RSKT-Seg

关注：

  • OVRSIS benchmark；
  • rotation-aware / multi-direction information；
  • remote sensing knowledge transfer；
  • open-vocabulary segmentation 如何真正适配遥感域。

9.2 ConInfer

Context-Aware Inference for Training-Free Open-Vocabulary Remote Sensing Segmentation

  • Venue: CVPR 2026 Findings
  • Code: https://github.com/Dog-Yang/ConInfer

它提出一个很值得思考的问题：

遥感场景具有强空间与语义上下文，仅仅逐 patch / 逐 pixel 独立预测是否合理？

建议重点看它如何在 training-free 条件下利用跨空间单元上下文，而不是只把注意力放在 backbone。

9.3 MM-OVSeg

Multimodal Optical–SAR Fusion for Open-Vocabulary Segmentation in Remote Sensing

  • Venue: CVPR 2026
  • Code: https://github.com/Jimmyxichen/MM-OVSeg

这一工作把 OVS 从单一 optical 推向：

Optical
+
SAR
+
Open Vocabulary

它很适合理解未来遥感开放世界感知为什么一定会走向多模态、多传感器，而不是只在 RGB benchmark 上竞争。

10. 2026 遥感前沿：变化检测与视觉基础模型

PeftCD

PeftCD: Leveraging Vision Foundation Models with Parameter-Efficient Fine-Tuning for Remote Sensing Change Detection

  • Venue: IEEE JSTARS 2026
  • Code: https://github.com/dyzy41/PeftCD

它把 SAM2 / DINOv3 + PEFT 引入变化检测。

阅读价值不只是看指标，而是思考：

  • foundation model 到底需要 full fine-tuning 吗？
  • LoRA / PEFT 能否保留 foundation prior？
  • SAM 与 DINO 的 representation 对 change detection 有什么不同？

11. 2026 遥感前沿：MLLM 与地理空间推理

11.1 GeoReason

Aligning Thinking and Answering in Remote Sensing Vision-Language Models via Logical Consistency Reinforcement Learning

  • Paper: https://arxiv.org/abs/2601.04118
  • Code: https://github.com/canlanqianyan/GeoReason

它关注的不只是“答案对不对”，而是：

推理过程是不是也真的正确？

重点概念：

  • pseudo-reasoning；
  • logical hallucination；
  • logical consistency reward；
  • RL-based RS-VLM reasoning。

11.2 RemoteReasoner

RemoteReasoner: Towards Unifying Geospatial Reasoning Workflow

  • Venue: AAAI 2026
  • Paper: https://arxiv.org/abs/2507.19280
  • Code: https://github.com/1e12Leon/RemoteReasoner

非常值得看，因为它开始从“一个模型对应一个任务”转向：

Instruction
   ↓
Reasoning
   ↓
Task Transformation
   ↓
Object / Region / Pixel-level Output

并利用 RL 增强推理自主性。

11.3 GeoViS

GeoViS: Geospatially Rewarded Visual Search for Remote Sensing Visual Grounding

  • Venue: CVPR 2026
  • Code: https://github.com/Zhang-Peirong/GeoVis

GeoViS 很适合理解遥感 MLLM 的一个真实困难：

一张超高分辨率图像里，目标可能只占极少像素。把整张图一次送进 MLLM，并不意味着模型真的“看见”了小目标。

它将 grounding 变成搜索 → 局部聚焦 → 条件定位，并引入 geospatial reward 与 visual search。

12. 2026 遥感前沿：Agentic Earth Observation

如果说 MLLM 是“能看图、能回答”，那么 Agent 研究的问题是：

模型能不能理解真实意图，并决定什么时候自己回答、什么时候调用检测器、分割器、变化检测、GIS 或光谱分析工具？

这是 2026 年遥感 AI 最值得关注的方向之一。

12.1 Earth-Agent

Earth-Agent: Unlocking the Full Landscape of Earth Observation with Agents

  • Venue: ICLR 2026
  • Code: https://github.com/opendatalab/Earth-Agent

特点：

  • ReAct-style agent；
  • 104 个 EO 专业工具；
  • Index / Inversion / Perception / Analysis / Statistics；
  • RGB 与 spectral EO；
  • 同时评估最终结果与 tool trajectory。

阅读时不要只看“大量工具”，而要看：

如何定义工具？
如何选择工具？
如何评估工具顺序？
如何评估参数是否正确？

12.2 OpenEarthAgent

A Unified Framework for Tool-Augmented Geospatial Agents

  • Venue: ECCV 2026
  • Paper: https://arxiv.org/abs/2602.17665
  • Code: https://github.com/mbzuai-oryx/OpenEarthAgent

它进一步把：

Optical / SAR
GIS
NDVI / NBR / NDBI
Detection
Segmentation
Change Detection

纳入统一工具系统，并对 reasoning trajectory 进行监督。

对于想做“真正可执行的地理空间 Agent”的同学，这比单纯学习 LangChain 更有价值。

12.3 RemoteAgent

RemoteAgent: Bridging Vague Human Intents and Earth Observation with RL-based Agentic MLLMs

  • Paper: https://arxiv.org/abs/2604.07765
  • Code: https://github.com/1e12Leon/RemoteAgent

RemoteAgent 关注的是一个更接近真实应用的问题：

用户通常不会说“请运行语义分割模型并返回第 4 类 mask”，而会说“帮我找出这里明显被开发的区域”。

因此 Agent 需要：

Vague Human Intent
       ↓
Intent Understanding
       ↓
Capability Judgement
       ↓
Direct MLLM Reasoning
       or
External Expert Tool
       ↓
Result

最值得思考的是 intrinsic capability vs. extrinsic tool execution：

  • MLLM 本身能可靠完成的任务，不必每次调用昂贵工具；
  • 对像素级、精度敏感任务，应交给专业 detector / segmentor / change detector。

这比“所有问题都调用所有工具”更接近实用 Agent。

13. 看完这些论文后，应该形成什么认识？

不是背住模型名，而是理解几条技术演进主线。

主线 A：从固定类别到开放世界

Closed-set classifier
→ CLIP

→ Open-vocabulary Segmentation

真正的 EO foundation model 需要面对：

  • optical / SAR / spectral modality；
  • GSD；
  • geography；
  • season；
  • temporal dynamics；
  • domain shift。

→ BLIP-2 / LLaVA

One Model
→ MLLM
→ MLLM + Expert Model

最终需要研究的不再只是一个 backbone，而是：

用户意图
+
多模态感知
+
推理
+
专业视觉模型
+
GIS / spectral tools
+
执行与反馈

14. 阅读建议：不要把论文读成摘要收藏夹

对本文每篇论文，至少回答下面几个问题即可，不需要写长篇形式化笔记：

  1. 它解决的真实问题是什么？
  2. 以前最接近的方法为什么还不够？
  3. 核心创新到底发生在数据、模型、训练、推理还是评测协议？
  4. 哪些模块是作者真正提出的，哪些只是调用已有模型？
  5. 训练阶段和测试阶段分别用了什么信息？
  6. 是否使用额外数据、额外模型、GT、TTA 或在线优化？
  7. 主表的比较是否公平？
  8. 最重要的 ablation 在验证什么？
  9. 代码中的入口文件、核心 module 和 evaluation script 在哪里？
  10. 它最明显的 failure case 是什么？

对科研新生来说，能回答这十个问题，比“看了多少篇论文”更重要。

结语

如果只记住一件事：

不要追着最新模型名字跑，要追技术问题的演进。

ViT 告诉我们如何用 Transformer 看图；
CLIP 让视觉与语言进入同一个语义空间；
Grounding DINO 把语言落到目标位置；
SAM 把分割变成 promptable foundation task；
SAM3 又进一步把文本概念引入检测、分割和跟踪；
DINOv3 展示强自监督视觉表征的价值；
遥感领域再把这些能力推进到多尺度、多时相、多传感器和开放词汇；
MLLM 开始进行地理空间推理；
Agent 则进一步决定什么时候应该推理，什么时候应该调用真正的 EO 专业工具。

理解这条主线，新生就不会在一年后只记住一堆已经过时的模型名，而能够继续读懂下一代工作。
